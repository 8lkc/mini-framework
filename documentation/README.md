# MINI-FRAMEWORK DOCUMENTATION

* Introduction
Mini-framework is a project aimed at creating our own framework which will implement three features: DOM abstraction, routing system. In this document, we'll provide a detailed explanation of how to use our framework.

## Features
The framework focuses on four key features:

    * Abstracting DOM :  Provides tools to simplify DOM manipulation, enabling dynamic creation and management of HTML elements with reduced complexity.

    * Routing System : Implements a simple routing system to navigate between different views or pages in a web application, facilitating URL management and user navigation.

    * State Management : Provides functionality to manage the state of elements within the application, facilitating dynamic updates and user interaction by maintaining consistent data synchronization.

    * Event Handling : Event handling involves capturing and responding to events triggered by the user, the system or other sources.
